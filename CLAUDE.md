# Claude Code Köprü Talimatı

Bu repository için ana talimat kaynağı `AGENTS.md` dosyasıdır.

Bir göreve başlamadan önce şu sırayla oku:

1. `AGENTS.md`
2. `docs/DECISIONS.md`
3. Görevle ilgili diğer `docs/` dosyaları

Ek kurallar:

- Büyük görevlerde önce kısa plan çıkar.
- Kullanıcının kapsamı dışında mimari değişiklik yapma.
- Çok sayıda dosya değiştirmeden önce etki alanını doğrula.
- UI görevlerinde ekranı gerçekten çalıştır ve görünümü doğrula.
- Kullanıcı onayı olmadan gerçek dosya, Excel veya veritabanı yazma kodu etkinleştirme.
