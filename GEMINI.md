# Gemini CLI Köprü Talimatı

Ana ve bağlayıcı talimatlar `AGENTS.md` içindedir.

Başlamadan önce:

1. `AGENTS.md`
2. `docs/DECISIONS.md`
3. Göreve ilişkin `docs/` belgesi

kurallarını oku.

Ek kurallar:

- Tahminle dosya veya API üretme.
- Görsel referansları üretim HTML'i olarak kopyalama.
- Kullanıcı onayı gerektiren domain işlemlerini otomatikleştirme.
- Sonuç raporunda çalıştırılan komutları ve başarısızlıkları açıkça belirt.
