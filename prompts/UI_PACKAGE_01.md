# UI Paket 01 — Tasarım Sistemi ve Uygulama Kabuğu

## Amaç

HasarBotu V2 için backend içermeyen, mock veri kullanan masaüstü UI temelini oluştur.

## Yapılacaklar

- React + TypeScript + Vite
- TypeScript strict
- Merkezi tasarım tokenları
- Açık tema
- Siyah koyu tema
- Kompakt / rahat yoğunluk
- Daraltılabilir ikonlu sol menü
- Üst bar
- React Router
- Mock navigation
- Durum Panosu placeholder
- Dosyalar placeholder
- Dosya Detayı placeholder
- 404 sayfası
- Error boundary
- Loading ve empty state componentleri

## Kapsam dışı

- Electron
- Backend
- PostgreSQL
- pCloud
- AI API
- Gmail
- Excel yazma
- Gerçek dosya erişimi

## Kabul kriterleri

- Sol menü sayfa değiştirir.
- Tema değişimi çalışır.
- Yoğunluk değişimi çalışır.
- Menü daraltma çalışır.
- Tercihler localStorage mock ile korunur.
- 1366×768 taşma yapmaz.
- 1920×1080 alanı verimli kullanır.
- Harici CDN veya uzak font yoktur.
- Stitch HTML kopyalanmamıştır.
